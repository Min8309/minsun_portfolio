03 / PROFILE

현장의 소통과 조율을,
콘텐츠 기획으로.

방송 소품팀에서 쌓은 8년의 제작 협업 경험에, 콘텐츠 기획과 구현 역량을 더합니다.

서로 다른 요청을 이해하고,
실행에 필요한 정보로 연결합니다.

브랜드 콘텐츠와 데이터 기반 콘텐츠 기획을 지향하는 박민선입니다. 방송 소품팀에서 8년간 현장과 베이스캠프, 제작팀과 외부 거래처 사이의 요청과 일정을 조율했습니다.

팀원들의 요청사항을 취합하고 처리 내용을 기록했습니다. 상시 소통 채널로 진행 상황을 공유하며 전달 누락과 오해를 예방하고자 했고, 외부 거래처의 작업도 제작팀과 소통해 일정이 겹치지 않도록 조정했습니다.

이 과정에서 필요한 정보를 정확하게 정리하고, 여러 사람의 작업을 연결하는 태도를 배웠습니다. 지금은 AI·웹 디자인 교육과정에서 익힌 제작 기술을 더해, 소재를 고르고 메시지를 구성하며 직접 구현하는 콘텐츠 기획을 준비하고 있습니다.

01. 요청을 정리하는 힘
현장·베이스캠프 팀원들의 요청사항을 취합하고 처리 내용을 기록했습니다. 서로 다른 요청이 빠짐없이 전달되도록 정보를 정리했습니다.
02. 정보를 연결하는 소통
상시 소통 채널을 운영해 진행 상황을 공유했습니다. 요청과 처리 내용을 기록으로 남겨 전달 과정의 누락과 오해를 예방하고자 했습니다.
03. 제작 일정을 조율하는 실행력
제작팀과 외부 거래처의 작업 일정을 확인하고 조율했습니다. 현장 요청과 외부 작업이 겹치지 않도록 제작팀과 소통했습니다.

현장에서 배운 태도, 프로젝트에서 이어가는 기획

방송 제작 협업 경험을 자료 정리와 콘텐츠 제작에 연결하고 있습니다.
