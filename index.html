04 / APPROACH

삶의 깊이, 배움의 속도.

깊이 있는 문제의식과 꾸준한 학습으로, 기술과 사람 사이의 거리를 좁힙니다.

사용자의 상황을 이해하고,
설계한 흐름을 직접 구현합니다.

UI/UX·웹 디자이너 박민선입니다. 복잡한 데이터와 콘텐츠를 사용자가 이해하고 선택할 수 있는 화면으로 정리하고, 웹·모바일 인터랙션으로 연결합니다.

3D 창작 공간, 신문 아카이브 게임, 시니어 서비스와 오디오 루틴 앱을 만들며 서로 다른 사용 상황을 다뤘습니다. 경성야록 팀 프로젝트에서는 전체 DB와 웹·모바일 게임 구현을 담당했습니다.

방송 소품 대여실에서 8년간 소품 제작·출고·대여·물류관리와 고객 응대, 홈페이지 관리 및 간단한 세무업무를 맡았습니다. 스튜디오에서는 촬영 보조·사진 이미지 수정 및 편집·고객 응대를 경험했습니다.

삶에서 얻은 관찰과 새로운 기술에 대한 배움을 함께 가져갑니다. 기능을 구현한 범위와 추가 검증이 필요한 부분을 구분하고, 결과를 확인하며 개선하는 태도를 중요하게 생각합니다.

01. 3D & Spatial UI/UX
WebGL/3D 가상 공간 연출, 캔버스 드로잉 브러시 엔진, 낮/밤 환경 라이팅 전환, 가상 쇼룸 및 인터랙티브 인터페이스
02. Frontend & Interaction
Vanilla JS (ES6+ Modules), CSS Grid & Flexbox, 반응형 웹 퍼블리싱, Zero-Dependency 경량 아키텍처, 상태 기반 동적 렌더링
03. Tech & Data Literacy
FastAPI 연동 및 RESTful API 구조 이해, Streamlit 프로토타이핑, Pandas 데이터 전처리 파이프라인, 머신러닝/YOLO 비전 AI 모델 협업

경험을 작업으로 연결하는 네 가지 강점

프로젝트에서 드러나는 접근 방식과 구현 사례입니다.

  • ✓
    01 / RIGOR

    8년의 꼼꼼함과 체계

    방송 소품 대여실에서 8년간 소품 제작, 물품 출고·대여와 물류관리, 홈페이지 관리 및 간단한 세무업무를 맡았습니다. 여러 업무의 일정과 물품 흐름을 챙긴 경험을 작업의 체계성과 꼼꼼함으로 이어갑니다.

  • ↔
    02 / EMPATHY

    장벽을 낮추는 실천적 소통

    소품 대여실과 스튜디오에서 고객을 응대하며 요청을 듣고 필요한 안내를 전달했습니다. 이 경험을 바탕으로 시니어 헬퍼의 큰 버튼·음성 입력처럼 사용자의 상황을 고려하는 화면을 구성합니다.

  • ◈
    03 / SENSE

    스튜디오 기반 시각 감각

    스튜디오에서 촬영 보조와 사진 이미지 수정·편집을 맡았습니다. 촬영과 이미지 편집 경험을 웹 화면의 시각 구성과 사진 기반 영상 작업으로 연결합니다.

  • ⌘
    04 / CODE

    AI & 데이터 인터페이스 구현

    경성야록의 전체 DB와 웹·모바일 게임 구현을 맡아 데이터 정리부터 인터랙션까지 연결했습니다.
