Design Philosophy & Competence

// 삶의 경험이 빚어낸 깊이 있는 질문, 기술을 관통하는 구현력

"인생의 전환점에서, 디자인의 본질을 명확히 정의합니다."

40대를 지나며 마주한 삶의 수많은 기로들은 저에게 '사람이 어떤 맥락에서 결정을 망설이고, 무엇에 감동하는가'를 깊이 있게 관찰하는 눈을 주었습니다.

지시받은 화면을 보기 좋게 그리는 것에 머무르지 않습니다. Ateliera의 3D 공간 연출부터 Pandas의 데이터 정제, 머신러닝의 예측 원리, 브라우저가 화면을 그리는 순수 자바스크립트 아키텍처까지 기술의 내부 원리를 집요하게 파고듭니다.

기획자의 사업적 의도를 꿰뚫고, 개발자의 언어(API, 모듈화, 상태관리)로 소통하며, 사용자가 마주할 복잡한 기술을 가장 정갈하고 직관적인 인터페이스로 번역하는 든든한 파트너가 되겠습니다.

01. 3D & Spatial UI/UX
WebGL/3D 가상 공간 연출, 캔버스 드로잉 브러시 엔진, 낮/밤 환경 라이팅 전환, 가상 쇼룸 및 인터랙티브 인터페이스
02. Frontend & Interaction
Vanilla JS (ES6+ Modules), CSS Grid & Flexbox, 반응형 웹 퍼블리싱, Zero-Dependency 경량 아키텍처, 상태 기반 동적 렌더링
03. Tech & Data Literacy
FastAPI 연동 및 RESTful API 구조 이해, Streamlit 프로토타이핑, Pandas 데이터 전처리 파이프라인, 머신러닝/YOLO 비전 AI 모델 협업
