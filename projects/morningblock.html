01 / 컨셉

내 아침을 블록처럼 조립하다

한 문장 소개

직장인이 원하는 시간과 순서로 모듈을 조합하고, 음성으로 따라가는 모닝 루틴 앱.

목표 경험

예약 모닝콜 → 알림 터치 → 저장한 루틴 실행 → 화면을 오래 보지 않고 듣기 → 완료 기록.

서비스 톤

파스텔 색상과 블로키 캐릭터, 반원 다이얼로 부담 없이 작은 아침 습관을 시작한다.

02 / 기획 의도

바쁜 아침에 선택과 화면 조작을 줄이기

문제 가설

출근 준비 중 뉴스·학습·운동 앱을 오가면 흐름이 끊기고, 정해진 긴 루틴은 지속하기 어렵다.

설계 방향

스트레칭·뉴스·외국어·명상·팟캐스트의 시간과 순서를 사용자가 조절한다. 낭독 모듈도 편집 화면에서 추가할 수 있다.

기획 메모

기본 루틴과 오늘만 변경을 분리해 일상 변동에 대응한다. 이 의도는 설계 가설이며 사용자 조사나 효과 측정 결과는 아니다.

03 / 사용자 흐름

한 번 구성하고, 매일 가볍게 실행

01 구성

내 루틴에서 이름·시작 예정 시간·모듈을 설정한다. 모듈당 1~30분, 드래그로 순서를 바꾸고 여러 루틴을 저장한다.

02 실행

오늘 화면에서 수동 시작하거나 모바일 모닝콜 알림으로 연결 루틴을 실행한다. 오늘만 변경은 수동 실행에 적용된다.

03 회고

일시정지·재개 후 끝까지 마친 루틴을 기록한다. 중단·건너뛰기는 완료에서 제외하고 실제 진행 시간을 집계한다.

04 / 화면·상태 구현

구성과 실행을 분리한 앱 구조

화면

오늘·내 루틴·기록·모닝콜·설정 메뉴. ModuleDial의 반원 다이얼, 모드별 이미지, 접히는 설정 카드와 캐릭터 애니메이션.

상태·저장

App.tsx에서 저장 루틴·오늘 변경·편집 초안·실행 세션을 구분한다. AsyncStorage에 루틴·기록·RSS 목록을 저장한다.

실행 제어

모듈 순서·남은 시간·일시정지 시간을 관리한다. 완료 기록은 일시정지 시간을 제외하며 한국 시간 달력으로 표시한다.

05 / 콘텐츠·오디오 구현

직접 작성한 레슨과 공개 RSS 연결

뉴스·외국어

뉴시스 RSS 제목·소개문을 읽는다. 기사 전문 수집·AI 요약은 구현하지 않았다. 4개 언어 × 3단계의 기본 레슨 12개를 제공한다.

팟캐스트

공개 HTTPS 오디오 RSS 등록·선택, 원본 오디오 재생, 이어 듣기 위치 저장. Luke 피드는 웹 읽기 제한 시 날짜가 표시된 스냅샷을 사용한다.

음성

기기 TTS와 언어별 음성 선택. 선택 기능인 클라우드 TTS는 별도 서버가 OpenAI tts-1-hd에 요청하며 Nova·Onyx를 지원한다.

모바일 실사용 검증과 운영 준비

모바일

외부 연결
