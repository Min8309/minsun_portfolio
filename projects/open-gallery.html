구현 범위와 확인 내용

  • React·React Router 기반의 화면 전환, 작품·상품 조회와 상태 기반 인터랙션을 소개합니다.
  • 기존 서비스 UI를 구현한 포트폴리오 프로젝트입니다. 공식 서비스 운영 실적이나 실제 결제·인증 구축 경험을 의미하지 않습니다. 브랜드·작품 이미지의 권리는 각 권리자에게 있습니다.
  • 2026-10-20 기준 GitHub 저장소의 배포 파일을 로컬 실행해 데스크톱 화면을 캡처했습니다. 이미지 안의 버튼은 작동하지 않으며, 직접 조작하려면 상단의 실제 사이트 버튼을 이용해 주세요.
