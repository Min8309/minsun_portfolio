# 박민선 포트폴리오

**Human, Code & Clarity** — 복잡한 데이터와 코드를 명쾌한 인터페이스로 번역하는 UI/UX·웹 디자인 포트폴리오입니다.

## 최근 반영 내용

- 면접용 비주얼 강화: 대형 타이포그래피 히어로, 부유하는 오브젝트 그래픽, 프로젝트별 SVG 콘셉트 커버와 대표 작업의 분할 레이아웃. 커버는 실제 서비스 스크린샷이 아닌 프로젝트 콘셉트 시각화입니다.
- 인터랙션 개선: 스크롤 등장 효과, 카드 호버, 현재 섹션 표시와 읽기 진행선. 상세 보기의 키보드 포커스 관리, Escape 닫기 및 모션 최소화 설정 지원.
- 미드나이트 네이비 컬러 컨셉 적용: 배경 `#0B0F19`(비중 기준 60%), 카드·박스 `#161F30`, 보더 `#1E293B`, 테크 시안 `#38BDF8`(비중 기준 30%), 앰버 `#F59E0B`(비중 기준 10%). 시안은 주요 버튼과 제목 포인트에, 앰버는 핵심 지표와 연락처 버튼에 사용합니다.
- 프로젝트 1 **Ateliera**와 프로젝트 2 **MY AI LIFE**의 데모 링크 연결.
- 프로젝트 6 **시니어 뇌건강 헬퍼** 소개, 기술 구성, 상세 보기와 서비스 링크 추가.
- 전체 프로젝트 수를 **6개**로 업데이트.

### 시니어 뇌건강 헬퍼

손자·손녀 캐릭터와 함께하는 모바일 중심 서비스로, 네 가지 기능을 2×2 버튼으로 구성했습니다.

- **두뇌 운동:** 숫자 순서, 경로 따라 그리기, 색상 맞추기, 소리·불빛 기억, 그림 짝 맞추기의 다섯 가지 단계별 활동.
- **물어보기:** 음성 인식과 글 입력 지원. 일반 대화는 준비된 응답 사용.
- **오늘의 기억:** 글과 음성 녹음 저장·재생. 기본 저장 위치는 현재 브라우저.
- **생활 도움:** Open-Meteo 날씨 조회와 기기 사진 촬영 화면.
- **기술 구성:** React 19, TypeScript, Vite 8, Tailwind CSS 4, 브라우저 음성·카메라 기능.

Supabase 클라우드 저장과 n8n·AI 사진 분석은 운영 연결 및 설정이 필요한 항목입니다. 실제 기기 권한, AI 안내 정확성 및 시니어 사용성 검증도 추가 확인 대상입니다.

## 로컬 실행

포트폴리오 자체는 `index.html`에 HTML·CSS·JavaScript를 담은 정적 페이지이며, 별도 패키지 설치나 빌드가 필요하지 않습니다. 위 기술 구성은 소개된 개별 프로젝트의 기술입니다.

저장소 루트에서 Python 3으로 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 됩니다.
